# 软件工厂数据库快照：导入与导出

需要：**Node.js 24+**、已启动的 **HugeGraph 1.7.0**，以及数据库用户名和密码。Docker / WSL 安装好即可，这里不展开。

下面使用当前数据库地址 `http://127.0.0.1:18080`。如果你的数据库端口是 **28080**，把命令里的 **18080** 改成 **28080**。

## 一、在哪里输入命令

打开 **PowerShell**，先复制下面这行，粘贴后按回车：

```powershell
cd "D:\桌面\软件工厂\数据库快照"
```

后面的命令都在这个窗口输入，把上面的路径改成仓库实际所在目录。

## 二、导入快照

复制下面这行，粘贴到 PowerShell 后按回车：

```powershell
.\导入快照.ps1 -Url http://127.0.0.1:18080 -Apply
```

然后按提示操作：

1. 输入下面这行确认文字，再按回车：

   ```text
   IMPORT DEFAULT/hugegraph @ http://127.0.0.1:18080
   ```

2. 输入数据库用户名（直接回车默认 `admin`）。
3. 输入数据库密码，密码会隐藏。
4. 等待完成，看到 `success: true` 就表示导入并回读验证成功。

默认导入 `data/current/graph-backup.json`，自动创建缺失的 Schema、节点和关系。建议导入新空库；一致的数据跳过，有冲突就停止，不会覆盖或删除旧数据。地址改了，确认文字中的地址也要跟着改。

**如果只想先检查、暂时不导入，输入这一行：**

```powershell
.\导入快照.ps1 -Url http://127.0.0.1:18080
```

它只检查，不写入数据库；没有报错后，再运行带 `-Apply` 的命令。

## 三、导出当前数据库

仍在同一个 PowerShell 窗口，输入：

```powershell
.\导出快照.ps1 -Url http://127.0.0.1:18080
```

按提示输入用户名和密码，等待出现 `success: true`。

导出的文件保存在本仓库的 **`data/export-日期时间/`** 文件夹中，包括：

- `graph-backup.json`：数据库结构和数据。
- `graph-backup.json.sha256`：校验文件。
- `verification.json`：导出检查记录。

导出只读取数据库，不修改数据，也不覆盖原快照。

要导入新导出的快照，在导入命令末尾加 `-File "快照的完整路径\graph-backup.json"`，将引号内替换为真实文件路径；旁边的 `.sha256` 文件要一起保留。

## 四、两个常见问题

- **连接失败或密码错误**：检查数据库是否启动、端口和账号密码是否正确。
- **提示禁止运行 PowerShell 脚本**：在当前窗口先输入下面这行，再重新运行导入或导出命令；只对当前窗口生效。

  ```powershell
  Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
  ```


当前快照：**79 个节点、70 条边**。数据库结构见[数据库说明](docs/数据库说明.md)，验证情况见[验收记录](docs/验收记录.json)。
