| 项目 | 值 |
| --- | --- |
| 导出时间 | 2026-10-31 01:34（北京时间） |

## 结构

```text
Capability（软件工厂根）
  ├─ HAS_CHILD → Capability（智能分析功能及下级能力）
  └─ HAS_CHILD → Capability（通用支撑能力）

Capability ── HAS_AGENT ──→ Agent ── HAS_VERSION ──→ AgentVersion

FieldGroup × 8：独立保存字段分类和 fields_json，不挂在能力树上。
```

| 顶点 | 数量 | ID 策略 | 属性 |
| --- | ---: | --- | --- |
| Capability | 18 | CUSTOMIZE_STRING | `name`；可选历史属性 `selection_policy_json` |
| Agent | 51 | PRIMARY_KEY(`agent_id`) | `agent_id`、`name`、`description`（均必填） |
| AgentVersion | 2 | CUSTOMIZE_STRING | 见下表 |
| FieldGroup | 8 | PRIMARY_KEY(`group_id`) | `group_id`、`name`、`display_order`、`fields_json`（均必填） |

| 边 | 起点 → 终点 | 数量 | 边属性 |
| --- | --- | ---: | --- |
| HAS_CHILD | Capability → Capability | 17 | 无 |
| HAS_AGENT | Capability → Agent | 51 | 无 |
| HAS_VERSION | Agent → AgentVersion | 2 | 无 |

模型、输入输出与优选指标均记录在版本普通属性中；当前没有 Model、ArtifactType 顶点及相关关系。Capability 保留旧 `selection_policy_json` Schema 声明；快照不进行清理、迁移。

## 属性及必填约束

除 `display_order` 为 `INT`，其他 20 个 PropertyKey 都是 `TEXT`，基数均为 `SINGLE`。JSON 内容是 TEXT 字符串，不是原生 JSON 属性。

| 顶点 | 属性 | 中文含义 | 必填 |
| --- | --- | --- | --- |
| Agent | agent_id | 逻辑 Agent 稳定标识 | 是 |
| Agent / Capability / FieldGroup | name | 名称 | 是 |
| Agent | description | 逻辑 Agent 能力描述 | 是 |
| AgentVersion | description | 当前版本独立能力描述 | 否 |
| AgentVersion | version | 业务版本 | 是 |
| AgentVersion | status | 状态（TEXT） | 是 |
| AgentVersion | invoke_kind | 调用方式 | 否 |
| AgentVersion | dsh_ref | DSH Tool 等执行入口引用 | 否 |
| AgentVersion | input_schema | 输入规格 | 是 |
| AgentVersion | output_schema | 输出规格 | 是 |
| AgentVersion | performance_evidence_json | 性能证据 | 否 |
| AgentVersion | constraints_json | 适用及运行条件 | 否 |
| AgentVersion | model_dependencies_json | 模型依赖 | 否 |
| AgentVersion | object_categories_json | 处理对象类别 | 否 |
| AgentVersion | selection_policy_json | 版本优选指标 | 否 |
| Capability | selection_policy_json | 历史遗留 Schema 声明 | 否 |
| AgentVersion | cost_json | 运行代价 | 否 |
| AgentVersion | effect_json | 任务效果 | 否 |
| AgentVersion | developer | 该版本开发人员 | 否 |
| AgentVersion | intermediate_artifacts_json | 中间产物简明规格 | 否 |
| FieldGroup | group_id | 分组稳定标识 | 是 |
| FieldGroup | display_order | 展示顺序（INT） | 是 |
| FieldGroup | fields_json | 本组字段定义及真实存储映射 | 是 |

`description`、`name`、`selection_policy_json` 是共享 PropertyKey 名称，但各节点的值独立，不自动继承。所有必填/可选规则直接取自快照的 VertexLabel，恢复时原样保留。缺省属性不补假值。
